# TextCapture 文字捕获

一款适用于 **Microsoft Edge** 浏览器的扩展插件，用于从禁止复制文本与图片的网站中提取可见内容，将页面正文提取为结构清晰的 **Markdown**，并支持一键复制或导出为 `.md` / `.txt` 文件。

提取结果在浏览器原生的**侧边栏**中展示，与原网页并列，宽度可拖拽到约占屏幕 1/3。

---

## ✨ 功能特性

- **一键提取**：在侧边栏点击按钮，自动识别页面正文并转为 Markdown。
- **Markdown 结构化渲染**：标题层级、加粗 / 斜体、有序 / 无序嵌套列表、引用、代码块、链接，以及**表格**（自动转换为 Markdown 表格）。
- **图片三模式**（可切换）：
  - `保留链接`：输出 `![](图片URL)`；
  - `截图嵌入`：通过 `captureVisibleTab` 截取可视区并按图片位置裁剪（仅截取当前可视区域内的图片，视口外自动回退为链接）；
  - `占位符`：统一输出 `[图片]`。
- **导出与复制**：复制 Markdown 到剪贴板、导出 `.md`、导出 `.txt`（带 BOM，Windows 记事本不乱码），并支持「源码 / 渲染」视图切换。

## 🚀 安装方法（Edge 加载解压缩扩展）

1. 打开 Edge，地址栏输入 `edge://extensions/` 并回车。
2. 打开页面左侧的**「开发人员模式」**开关。
3. 点击**「加载解压缩的扩展」**，选择本项目文件夹（`TextCapture文字捕获`）。
4. 工具栏出现 **T** 图标即表示安装成功。

> 如需更新代码：在 `edge://extensions/` 页面点击该扩展卡片上的**「重新加载」**按钮即可。

## 📖 使用步骤

1. 用 Edge 打开你想提取内容的网页（建议先刷新一次，确保 `unlock.js` 在页面脚本前生效）。
2. 点击工具栏上的 **TextCapture 文字捕获** 图标 → 右侧自动展开侧边栏。
3. 在侧边栏点击**「一键提取」**，稍候即看到以 Markdown 渲染的页面正文。
4. 按需操作：
   - 在顶部下拉框切换**图片模式**（链接 / 截图 / 占位），再重新提取；
   - 点击**「复制」**将 Markdown 复制到剪贴板；
   - 点击**「导出 .md」** / **「导出 .txt」** 保存为文件；
   - 用**「源码 / 渲染」**开关查看原始 Markdown 或渲染效果。

## ⚠️ 已知限制与兼容性

- **受限页面**：`edge://` 内部页、扩展商店页等浏览器禁止注入脚本的页面，无法提取。
- **截图范围**：「截图嵌入」模式仅能截取当前**可视区域**内的图片；视口外的图片自动回退为链接或占位符。
- **富媒体**：视频、音频、Canvas、SVG 等不纳入文本提取，图片按所选模式处理。

## 🔒 隐私与安全

- 扩展**仅在用户主动触发提取时**读取当前页面 DOM，不后台采集、不上传任何数据。
- 所有文本与图片处理均在本地完成；「截图嵌入」生成的 base64 图片仅用于本地渲染与导出，不会外发。
- 所需权限（`tabs` / `scripting` / `sidePanel` / `clipboardWrite`）均用于实现上述提取与导出功能，无多余权限申请。
